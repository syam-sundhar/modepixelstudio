# MODEPIXEL — AI Fashion & Creative Production Studio

> An independent, luxury AI-powered fashion and commercial product photography studio website that transforms raw product references into world-class commercial campaigns.

---

## Brand Identity & Art Direction

- **Brand**: MODEPIXEL
- **Positioning**: Independent AI fashion photography & digital creative production
- **Founding Art Direction**: Luxury fashion editorial paired with computational fidelity
- **Palette**: Deep Charcoal (`#08080a`), Warm Editorial White (`#f7f7f5`), Electric Lime (`#d4ff00`)
- **Contact**: `modepixelstudio@gmail.com` | `@modelpixelstudio`

---

## Features

- **Luxury Fashion Editorial Aesthetic**: Editorial serif headings, minimal dark canvas, subtle analog film grain.
- **Cinematic Navigation & Interactions**: `requestAnimationFrame`-based cubic-bezier smooth scrolling engine with navbar offset compensation.
- **Fluid Services Capabilities**: Intent-debounced service interaction with 700ms photo crossfading.
- **High-Fidelity Portfolio Exhibition**:
  - *Project 01*: Oversized Streetwear Editorial (T-Shirt Campaign)
  - *Project 02*: Icy Ombré Plush Knit Hoodie (Luxury Knitwear)
  - *Project 03*: Architectural Kinetic Sneaker (Footwear & Hardware)
  - *Project 04*: MODEPIXEL ESSENCE Botanical Serum (Beauty & Skincare)
- **Interactive Before/After Fidelity Slider**: Real-time comparison between raw garment reference and final campaign output.
- **Immersive Case Study Modal**: 8-stage case study structure with high-resolution lightbox inspection.
- **Client Inquiry Engine**: Multi-field intake with file upload, direct WhatsApp brief synchronization, and email integration.

## Getting Started

### Prerequisites

- Node.js (v18+)
- npm / yarn / pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/syam-sundhar/modepixelstudio.git

# Navigate into project directory
cd modepixelstudio

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
